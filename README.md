# Boat Link Medical Equipment Trading L.L.C

A modern, responsive medical equipment catalog website developed for **Boat Link Medical Equipment Trading L.L.C**, a UAE-based supplier of healthcare and medical technology solutions.

---

## Overview

This project was built to provide a professional online presence for a medical equipment trading company while offering a scalable and easy-to-manage product catalog system.

The website enables visitors to browse product categories, explore medical equipment, search products, view detailed specifications, and directly contact the company via WhatsApp.

## Core Functionalities

### Dynamic Category Management

All categories are managed through centralized JavaScript arrays, making future updates simple and scalable.

### Dynamic Product Management

Products are stored in a structured JavaScript object format:

```javascript
{
  id: 1,
  name: "Product Name",
  image: "product-image.webp",
  category: "Category Name",
  shortDescription: "Short summary",
  fullDescription: "Detailed description",
  manufacturer: "Manufacturer",
  model: "Model Number",
  specifications: {},
  features: [],
  certifications: [],
  notes: ""
}
```

Adding a new product only requires inserting another object into the products array.
